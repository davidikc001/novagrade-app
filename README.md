# NOVA GRADE

Track, predict and improve your grades. A CGPA tracker built for university students.

## Download

Get the latest version from the [Releases page](../../releases/latest) and download the `.apk` file.

## Install

1. Open the downloaded file on your Android phone.
2. If Android asks, allow installing from this source (your browser or file manager).
3. Open NOVA GRADE and create your account.

Requires Android 7.0 or newer. After the first install, most updates arrive inside the app.
